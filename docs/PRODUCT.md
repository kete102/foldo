# Product vision

## Mission

Foldo aims to make everyday document tasks simple, fast and accessible while minimizing unnecessary exposure of user files.

## Audience and positioning

Initially focus on Spanish-speaking users who need occasional or recurring document operations: students, individuals, freelancers and small teams. Established alternatives include iLovePDF and Smallpdf. Foldo aims to differentiate through local-first processing, a clear interface, transparent limits and useful free tools rather than competing solely on feature count.

## Product principles

- Process documents locally whenever feasible; explain when an upload is required.
- Make basic tasks available without mandatory registration.
- Prioritize speed, accessibility and clear error recovery.
- Build public tool pages around genuine search intent and useful content.
- Avoid advertising and unnecessary friction as a proposed product policy.

## MVP scope (proposed)

Start with PDF merging, splitting, rotation, page organization, PDF-to-image and image-to-PDF. Validate browser feasibility, quality and demand before committing to the final six-tool lineup. Compression, OCR, Office conversion, cloud storage and reusable workflows are later candidates.

## Monetization (proposed, not implemented)

| Capability | Free | Pro |
|---|---|---|
| Price | €0 | €4.99/month or €39.99/year |
| Local basic operations | Unlimited, subject to device capability | Included |
| Server operations | 5/day | Higher limits, TBD |
| Server file size | 50 MB | 500 MB |
| Cloud storage | Not included | 5 GB |
| Advanced features | Limited | Batch processing, OCR, history, versions and workflows |

The annual price is approximately €3.33/month equivalent, saving about 33% against twelve monthly payments. Billing terms, taxes, quotas and feature availability must be validated before publication. Monthly and annual billing are two options for the same Pro tier, not separate feature tiers.

## Success measures

Track successful document operations, tool-page organic acquisition, completion rate, repeat usage, conversion to paid plans and processing cost per operation. Define targets after establishing a baseline. Analytics must not collect document contents or filenames.

## Non-goals for the MVP

Full collaborative editing, enterprise administration, a complete Office suite and advanced cloud workflows are outside the initial scope.
