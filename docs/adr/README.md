# Architecture Decision Records

ADRs record significant architectural decisions, their context and trade-offs. Use sequential identifiers and descriptive filenames. Keep historical decisions; supersede them with a new ADR when necessary.

## Template

```markdown
# ADR-NNNN: Title

## Status
Proposed / Accepted / Superseded / Rejected

## Context
What problem and constraints motivate the decision?

## Decision
What approach is selected?

## Consequences
Benefits, costs and limitations.

## Alternatives considered
Other options and why they were not selected.
```
